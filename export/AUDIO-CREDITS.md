# Music credits

Five tracks from Freesound.org, used as background music per screen (see
`src/audio/music.js`). All downloaded as their official HQ preview MP3
(128kbps) -- small, web-friendly, and exactly what Freesound itself serves
for streaming, not a re-encode of the original upload.

| Screen(s) | Track | Artist | License |
|---|---|---|---|
| Main menu | ["Lo-Fi Tokyo"](https://freesound.org/s/592887/) | [YellowTree](https://freesound.org/people/YellowTree/) | CC BY 4.0 |
| Bath Bubbles | ["Rainy days *Final Version* (Acoustic/Piano)"](https://freesound.org/s/695951/) | [Mark_Murray](https://freesound.org/people/Mark_Murray/) | CC BY 4.0 |
| Wordlebara | ["Solemn Asian String Melody Loop (Wind, Water, Wood)"](https://freesound.org/s/840945/) | [CVLTIV8R](https://freesound.org/people/CVLTIV8R/) | CC0 (no attribution required, credited anyway) |
| Orange Catch, Memory Match, Capy Stack | ["Crossed Path"](https://freesound.org/s/609209/) | [Kjartan Abel](https://kjartan-abel.com/library) | CC BY-SA 4.0 |
| Capy Run | ["gaming circuit beat.wav"](https://freesound.org/s/345391/) | [zagi2](https://freesound.org/people/zagi2/) | **CC BY-NC 4.0** |

Orange Catch, Memory Match and Capy Stack don't each have a dedicated track
yet -- they share "Crossed Path" (replaced AudioCoffee's "Funny - Positive
Background," which didn't land as chill/lo-fi as the rest of the set).

**The `zagi2` track is NonCommercial-licensed.** Fine for this project as-is
(non-commercial), but it's the one track that would need swapping out if
that ever changes -- everything else here is plain CC BY or CC0.

Full audio files are not committed raw to `export/` (they live in
`src/audio/tracks/`, bundled into the build); this file is the license
record CC BY requires.
